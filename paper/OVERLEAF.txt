GitHub synchronization

Overleaf's native GitHub integration is a premium feature. Its push/pull buttons
must be used explicitly; it is not continuous automatic synchronization. It
connects an entire GitHub repository, not just paper/. Prefer a paper-only
repository if using that integration. An existing Overleaf project can create
a new linked GitHub repository; it cannot be linked to an existing repository
through the native GitHub interface. Account authorization is performed by the
maintainer. Keep the paper repository private until publication is approved.

Local bidirectional workflow

Overleaf's Git integration provides a separate checkout of this project. Obtain
its clone URL from the project menu and authenticate using the maintainer's
Overleaf token in the Git credential manager, never in a shared URL or file.
The project owner needs the applicable Overleaf entitlement.

The main GazeSync repository provides tools/overleaf.py. It synchronizes only
the reviewed manuscript/figure/table files. It makes no network requests or
Git commits and refuses to overwrite edits on the receiving side.

From the GazeSync repository, before editing either copy:
  python3 tools/overleaf.py export --directory /path/to/overleaf-checkout
  python3 tools/overleaf.py export --directory /path/to/overleaf-checkout --apply

The first export accepts an empty destination or files identical to this ZIP.
For an existing Git clone, run git pull --ff-only inside that checkout first.

After editing locally in GazeSync:
  python3 tools/overleaf.py export --directory /path/to/overleaf-checkout
  python3 tools/overleaf.py export --directory /path/to/overleaf-checkout --apply
Then inspect git diff, commit and push in the Overleaf checkout.

After editing in Overleaf:
  git -C /path/to/overleaf-checkout pull --ff-only
  python3 tools/overleaf.py import --directory /path/to/overleaf-checkout
  python3 tools/overleaf.py import --directory /path/to/overleaf-checkout --apply
Then inspect the changes, compile the paper, and commit/push GazeSync.

Commands without --apply are previews. The local sync baseline is stored under
GazeSync/artifacts/overleaf-sync and is excluded from Git and the ZIP. Keep it
between runs. Simultaneous conflicting edits require manual reconciliation;
the tool does not force-push, delete files or choose a winner. New figure/input
files require a deliberate update to the mapping in tools/overleaf.py.

Without Git access, download the Overleaf source ZIP, extract it to the same
separate sync directory and use the same import command. Export creates the
updated local copy; upload its changed files through Overleaf. Preserve the
sync baseline so remote edits cannot silently overwrite local work.
