GAZESYNC / CONTENT SURFACE

Move the content. Keep its coordinates.

This page combines a vector image and ordinary HTML text in one content layer. Drag, zoom or rotate them together; the frame stays fixed.

FIELD NOTES / 01

A new perspective

Rotate the page, move it to a different corner, or zoom in to read. Its original top-left remains the content origin. An image, a text block, or a group can use this same surface.

Drag · Wheel / pinch · Two-finger twist · [ ] rotate · Arrows move · Home restore

No eye measurements are generated here. Connect your tracker with app.pushGaze(sample, receivedTimeMs); the helper records each rendered transform and the input events that caused it. Use the interaction lab for simulated gaze.

import { createGazeSurface } from 'gazesync/browser'
const app = createGazeSurface(frame, content, {
  contentWidth: 720, contentHeight: 600,
  contentId: 'reading-page', panBounds: 'none',
})
app.controller.rotate(Math.PI / 12, performance.now())
app.controller.move(40, 20, performance.now())
